🔧 SRX210 Reset & Configuration Wizard

Follow the steps below to reset your SRX210 device and generate the configuration file.
  1. Ensure that you are currently open this in a Windows PC.
  2. Download the Reset Bat file and its command files. SRX210_Reset.bat  •  reset_commands.txt
  3. Click the bat file and give current IP and Password.
  4. After entering the current root password: 1. You will see root@%
    2. Paste the commands from the clipboard using CTRL+SHIFT+V then Enter then
    3. Wait for: New password:
    4. Enter your NEW root password manually
    5. Retype the NEW root password
    6. Then enter "Commit" and wait for confirmation.
